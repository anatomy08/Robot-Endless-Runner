# Robot Runner

A 3D endless runner built with Unity and C# using an MCP-connected, AI-assisted development workflow. I directed the gameplay architecture, procedural environment generation, obstacle design, asset integration, testing, debugging, and iteration.

## Play the WebGL Demo

[Play Robot Runner on itch.io](https://jeffreyexpectacion.itch.io/robot-runner)

## Project Overview

Robot Runner challenges the player to survive an endlessly generated course while avoiding obstacles and moving through a changing environment. The project was designed as a practical demonstration of Unity gameplay systems, procedural content generation, and rapid development using AI-assisted tools under my direction.

## Key Features

- Endless procedural track generation
- Runtime spawning of platforms, buildings, and obstacles
- Reusable environment segments
- Increasing obstacle variety during play
- Score and progression systems
- WebGL deployment for browser-based access
- Iterative testing and gameplay balancing

## Technical Highlights

- Built with **Unity** and **C#**
- Procedural spawning keeps the environment extending during gameplay
- Gameplay systems are separated into focused components for easier maintenance
- Reusable content reduces repeated scene setup
- WebGL build provides a zero-install recruiter demo
- AI-assisted implementation was used to accelerate coding and debugging while I controlled requirements, architecture, testing, and final decisions

## Development Workflow

This project used a Model Context Protocol-connected AI workflow inside the Unity development process. My responsibilities included:

- Defining gameplay requirements and system behavior
- Directing code architecture and implementation
- Reviewing generated code and correcting issues
- Testing gameplay systems in Unity
- Integrating assets and tuning game feel
- Preparing and publishing the WebGL build
